# Mode multijoueur

## Version simple : alternance
- Joueur 1 : ping-pong puis Dobble
- Joueur 2 : ping-pong puis Dobble
- Le score avance chacun son tour

## Version coopérative
- un joueur fait tomber la balle
- un autre joue le jeton
- un autre valide la carte
- le selfie final réunit tout le monde

## Variables minimales à ajouter
- score_j1
- score_j2
- joueur_actif
- nb_manches
- historique_symboles

## Effets possibles
- avance joueur actif
- avance équipe
- bloque un tour
- échange de tour
- bonus selfie collectif
